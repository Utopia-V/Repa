# 重放只经课程结构读课程

状态：已落地

## 问题

一个空间以后要能学几门课，每项任务也要按它开始时的那一版课程计算，而不是按今天的课程。两件事都要先回答一个问题：重放学习记录、算出结论、XP、学生模型、补救、测验和菜单，到底需要课程的哪些东西。

测试版里这些计算到处直接拿完整的课程索引（`CourseIndex`），而且拿的是空间当前换用的那一门。完整课程里有题面、讲解、判分方式、代码题的测试，随包的 Python 课约 1.5 MB；计算实际用到的只是其中很小的一部分，却没有一处写明是哪一部分。不先划出这条边界，“任务记下开始时的结构”就不知道该记什么，多门课时也说不清一门课向这条主线提供什么。

## 决定

课程结构在 `packages/learning/src/course-structure.ts`。`CourseStructure` 是纯数据：课程的标识与版本，按课程顺序的 topic；每个 topic 有展开状态、分钟数、先修、正权重的包含关系和知识点；每个知识点有关键先修、例题与三个题池的题目编号，以及练习题里要由模型判分的那几道。`StructureIndex` 只由这份数据建出查找表（topic、题目归属与题池、有测验题的 topic）和学生模型的图，所以结构写成 JSON 再读回，建出的东西与原来相同。

学习会话从当前课程取出结构（`courseStructure(resolved)`），与课程内容取自同一门课；新任务开始时把这份结构写进学习记录，此后这项任务按它计算，见[学习记录自足](2026-11-18-self-contained-records.md)。

### 读取落在哪边

| 读取 | 读哪边 | 理由 |
| --- | --- | --- |
| 作答归属哪个 topic、知识点（证据、测验结果、测过次数） | 结构 | 决定结论与学生模型 |
| 课的知识点顺序、必做与开放题、开始时的要求、分钟数 | 结构 | 决定课的进度、结论与 XP |
| 先修、关键先修、包含关系、学生模型的图 | 结构 | 决定补救、资格与 FIRe |
| topic 顺序、展开状态、有测验题的 topic | 结构 | 决定菜单、进度、测验抽样 |
| 选题时某个题池里有哪些题、开放题排在最后一道必做题之前 | 结构 | 决定出哪道题 |
| 任务事实里记下的课程标识与版本 | 结构 | 课程身份 |
| 题面渲染、选项编号、讲解与例题页 | 内容 | 给人看的，要完整题目 |
| 判分、题目与题面版本、试运行 | 内容 | 要答案、比较方式、测试与运行前导 |
| 调用方能否显示、能否运行 Python、有没有可用模型 | 内容 | 所需服务是否可用，随调用方而变，不是课程的性质 |
| topic、知识点、菜单候选的标题，课程标题，辅导与引用 | 内容 | 给人看的；标题改字不应算作结构变了 |

菜单的标题因此由调用方按 topic 给出（`learningMenu` 的 `title` 参数）。菜单接受一项课时要求“每个没过的知识点的必做题都能用”：哪些是必做题看结构，能不能用看内容。

### 一条空间级的主线

重放是一台、按空间的事实序号推进：一个当前任务、一个奖励账本、一组测验计数、一个日目标。结构只是这台重放的输入，学习状态的键带上课的键（见[课的身份与位置](2026-11-20-course-identity.md)），两门课的编号可以相同。新任务开始时取代上一项任务、XP 门槛按人累计、补救挡住其他任务，这些都跨课成立，属于学习的人；课只提供内容与图。每项任务引用它开始时的结构，换的是“取哪一份结构”，不是重放的条数。

## 考虑过的其他做法

**按课程分别重放，每门课一台。** 看起来能让每门课的 XP 和学生模型各自正确，但会悄悄改变测试版已经给出的读数。测试版数据里的丁先学随包 Python 课（py01 通过，20 XP），再换用自制课学 os01（15 XP）。测试版用当前的课重放整段日志，py01 的题不在自制课里，没有证据，被下一项任务取代而记为 `ended`，今日与累计 XP 为 15，学生模型只有 os01。按课分别重放时，Python 那一台照旧算出 py01 通过、20 XP，累计变成 35，学生模型多出 py01。这比测试版“更合理”，却违反了升级不改读数：学习者昨天看到 15，升级后看到 35，而他什么也没做。

它还拆开了本属于人的状态：一门课里最后一项没做完的任务，在那一台里看不到另一门课的新任务，就永远不会被取代，仍是“进行中”；测验门槛和日目标按课各算一份，两门课各学 100 XP 时谁也到不了 150 的门槛。

**只把 `CourseIndex` 换个名字传下去。** 不划边界，任务仍不知道该记下什么，完整课程也存不进学习记录。

## 影响

- 划这条边界时没有改变任何读数：第一个测试版留下的五个空间（加上丁换课前的快照），学习记录的每个前缀在最后一条事实时与 25 小时后各读一次，结果与标签 `v0.1.0-test.1` 算出的完全相同（735 个前缀、1470 次读数，见 `packages/learning/test/fixtures/test1/README.md`）。这组对照现在只在测试里重放。

- 结构与内容同时存在于学习会话里，以后有人可能又从内容读结论所需的东西。`StructureIndex` 是重放、菜单、进度唯一接受的课程参数，类型上就拿不到内容。
- 选题经结构列出题池再到内容里取题：题目编号在一门课里重复时（课程检查不允许），取到的是后出现的那道，与题目查找一向的做法相同。
- 结构里没有题目版本。判分是否过期、能否再判按内容判断（同一门课、同一道题、学习者看到的同一份题面），不按结构。
