# Python 运行器的规矩

用法、沙箱和已知限制见 [README](README.md)。

- **运行的是学习者与课程作者的代码。** 放宽沙箱的任何一项限制之前，先按[沙箱](README.md#沙箱)一节评估；运行比课程核对更不可信的内容之前要重新评估。
- **课程核对与判分共用 `runner.py`。** 改动要在 Linux 沙箱和页面 Worker 两个宿主上都验证：核对通过的题，判分时不应得出另一种结果。
- **Python 是目前唯一的学科运行时。** 它是学习插件使用的一种学科能力，不进底座；学习插件以后不应假定只有它，见 [#99](https://github.com/Utopia-V/repa/issues/99)。
