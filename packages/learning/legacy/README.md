# 测试版留下的定义

这里冻结着解释测试版学习记录所需、而以后的安装包里可能不再相同的内容。

`test1-python.json` 是测试版 `v0.1.0-test.1` 随包的 Python 课的课程结构（`CourseStructure`），由标签上的 `packages/learning/courses/python/` 经 `courseStructure` 取出，写成一行 JSON，35942 字节，sha256 为 `2789be368efad2f4f28faa05be4a589381961d9140f8db734f43aaaf79ab5906`。首次打开测试版的空间时，学习插件按它为只学过随包课的学习记录写下旧日志基线：测试版当时就是按这一份解释日志的，以后的版本改了随包的课，旧日志的读数也不变。生成它时随包的课与标签上的相同，所以它也等于当时 dev 上随包课的结构。

这些文件不改；要重新生成，用标签上的课程文件，结果须与上面的摘要相同。
