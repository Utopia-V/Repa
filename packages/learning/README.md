# 讲解与实际反馈

`@repa/learning` 提供 `learn-with-feedback` Pi Skill。你可以从一个问题开始，使用已有教材、讲义与尝试取得讲解、提示或反馈。方法区分学习者的实际作答、所用帮助和助手完成的成果，让后续解释能够针对这次遇到的困难。

有接续价值的原始尝试、材料引用和解释可以通过空间的内容工具保存，下一次需要细节时再读取。当前提供的是教学辅助；沿知识关系更新学生状态、据此选择学习任务的闭环程序入口仍待研究和实现。

官方默认以 `repa-teaching` 加载这一方法。关闭这一项会移除方法，已有文档与学习语境绑定继续保留。方法正文见 [learn-with-feedback](skills/learn-with-feedback/SKILL.md)，默认启用、替换方式和验证范围见[官方学习组合](../../docs/development/official-learning.md)。
