# 写课的规矩

格式、检查命令和自查见[写课说明](README.md)，字段定义在 [`src/format/schema.ts`](../src/format/schema.ts)。

- **题目 id 是学习记录引用的身份。** 发布后不改、不复用；题目实质换了内容就给新 id，旧 id 登记进 `retiredIds`。删掉一道题，学习者过去对它的作答就不再作为证据，已通过的课可能因此不再通过。
- **改答案会重判过去的作答。** 题面不变而答案改了，过去的作答按新答案重判，对错两个方向都生效，见[题目版本](../README.md#题目版本)。课开始时记下这节课的练习清单与分钟数，所以加题、改分钟数只影响之后开始的课。
- **四个题池、六个编程题型和只有 Python 的判分运行时是测试版的格式，不是题目结构的设计。** 不要据此假定同一题池里的题可以互换；下一阶段改为知识点、考法、变式，题型由课程定义，见[题目结构提案](../../../.agents/notes/proposed/architecture/2026-11-02-item-structure.md)与 [#99](https://github.com/Utopia-V/repa/issues/99)。
