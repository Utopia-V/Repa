# 学习插件的开发规矩

底座的[开发规矩](../base/AGENTS.md)在此同样适用。以下几条为学习插件特有。

- **学习记录只记对推断学习状态有用的事实。** 即所出的题目及其版本、学习者的作答、判分结果、出题与作答的时间、作答前是否看过讲解或询问辅导，以及任务类型。界面、学生模型、进度和 XP 均由这些事实计算得出。
- **没有证据，则既不算对也不算错。** 中途离开、判分失败、模型表示无法准确判分，均属尚无证据：不阻塞任务，也不记为失败。待条件具备后补判，学习状态随之重算。
- **检查设在题目产生之处，检查与判分使用同一套判断。** 题目可能由我们、社区或学习者一端的模型写出，检查均须能在该处运行；经过检查的题目，判分时不应得出另一种结果。
- **每个数值均须命名并注明出处。** 出处为 Math Academy 公开、Repa 猜测或研究结论。尚未确定的数值列入学习插件的假设文档，并写明何种证据会使其改变。
