# 学习插件的开发规矩

底座的[开发规矩](../base/AGENTS.md)在这里同样适用。下面几条是学习插件自己的。

- **学习记录只记对推断学习状态有用的事实。** 出了哪道题、哪个版本，她答了什么，判成什么，什么时候出题、什么时候作答，答前有没有看讲解或问辅导，这是哪种任务。界面、学生模型、进度和 XP 都从这些事实算出来。
- **没有证据，就不算对也不算错。** 中途离开、判分失败、模型说判不准，都只是还没有证据：不卡住任务，也不记成失败。等条件具备了再补判，学习状态随之重算。
- **检查放在题目产生的地方，检查和判分用同一套判断。** 题目可能由我们、社区或模型在学习者那边写出，检查都要能在那里跑；检查过的题，判分时不应冒出另一种结果。
- **每个数值都起名，并写明出处。** 出处是 Math Academy 公开的、Repa 猜的，还是研究得出的。还没摸清的数值，列进学习插件的假设文档，写明什么证据会让它改。
