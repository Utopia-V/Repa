# 官方学习能力

学习产品要减少学生在学习之外的心智负担，让已有材料与实际表现持续影响后续帮助。它采用 Math Academy 式的学习闭环，并利用模型补足讲解、开放作答理解和资料不足时的内容建设；算法与状态由学习能力持有，不进入通用底座。

这里记录已确认的领域含义，不规定尚待研究的评分公式、掌握阈值或调度器。当前代码中的文档背景与 FSRS 复习项是原型实现，完整闭环仍待建立。研究问题见[学习闭环与研究问题](../../docs/research/learning-loop.md)。

## 概念

**学习目标**：学习者希望形成的理解或能力，可以有具体范围、期限和熟练要求。多个目标可以共享内容和实际表现，但各自是否满足要求仍需分别判断。

**Topic**：用于组织知识关系、学习与复习状态的主题。它与课程章节、文件或卡片没有固定的一一对应关系。

**KP（Knowledge Point）**：一个 topic 内帮助学习者逐步掌握内容的教学台阶。KP、topic 和单道题各有作用，中文说明需要区分它们，不能都含混地叫作“知识点”。

**学习内容**：可以持续复用和修订的路线、材料、题目、参考题解与知识关系。内容的来源和版本用于解释过去的作答，后来的编辑不改变当时实际看到的题目。

**先修与练习覆盖**：先修说明学习后续内容所需的基础；练习覆盖说明某项活动实际上练到了哪些部分。理解题目需要某个概念，不代表这次练习充分训练了它。

**实际作答**：学习者针对具体内容作出的回答、推导或操作，连同当时的帮助条件与可观察结果。独立完成、提示后完成、看解后复述和助手生成的答案具有不同含义。

**学生状态**：学习能力依据实际作答、知识关系和时间形成的当前判断。它与原始作答分别保存，可以随新证据、更正或算法变化重新计算和解释。

**学习任务**：为目标安排的教学、练习、诊断或复习活动。任务选择使用当前状态和已有内容，而不是每次会话重新生成整套路线。

## 关系

- 已有课程和材料优先持续使用；缺少可用学习资料时，模型补上内容作者的角色。资料、实际学习反馈与社区贡献共同帮助纠正内容和关系，模型不能只依靠自己的重复解释维持正确性。
- 新作答改变学生状态，状态改变可学内容、需要复习的部分或后续帮助。调度和可确定计算的传播由算法承担，模型负责讲解、提示及开放语义判断。
- 学习内容与个人作答有不同生命周期。共享课程和题解可以被修订或复用，个人记录保留其实际经历及所用内容的版本。
- 诊断、教学、新学习和复习属于同一闭环。一次活动可能涉及多个 topic，但归因需要实际练习覆盖与帮助条件，不能只沿先修关系一律登记成功。
- 图谱、参考卡和可导出图片帮助理解及回顾；呈现方式不另行建立一套需要学习者协调的独立调度。
- 学习插件向 Agent 提供当前需要的背景和可调用操作，持久领域状态仍归插件。文档背景可以提供材料入口，但不替代学生状态与调度的计算。

## 不变量

- 学习者的表现与助手的产出分别表达，能运行的代码、已读材料或已完成活动不自动等于掌握。
- 内容、作答记录、当前估计和未来安排保留各自含义。更正判断保留原始依据，算法更换不丢失重新解释所需的事实。
- 后续帮助应当受到新的实际表现影响。只证明保存与读取成功，不足以证明学习闭环或学习效果成立。
- 领域实现可以演变，但不能把持续使用已有内容、用户更正和反馈驱动后续帮助削弱为提示纪律。
