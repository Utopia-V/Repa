# 持续学习

从用户的目标、已有材料和当前学习语境接续学习。整体路线只需让人看清范围、方向和关键关系；接下来要做的部分再展开成可以开始的活动。当前问题的讲解和实际反馈交给 `learn-with-feedback`，一次问答可以直接完成，不必先建立整套路线。

按本次任务读取参考：

- 建立或调整路线、连接材料与实际记录、保存图示或实验、恢复跨会话进度时，读 [路线、材料与实际记录](references/route-and-records.md)。
- 决定接下来学什么、混合新学习与巩固、安排下一次观察或考虑 FSRS 时，读 [新学习与复习选择](references/review-decisions.md)。

路线、活动材料、实际记录和未来安排都在空间的普通可编辑文档中持续维护。先读已有正文和引用，再局部修改；内容与语境工具负责实际保存，已启用的 `organize-learning` 可以指导重组与绑定。语境保留当前重点和再用入口，详细正文按需读取，因此不同会话可以沿用同一份内容，也能承接用户的人工调整。

按当前已启用的能力安排时间。`plan-learning` 可以帮助估计工作量；涉及相对日期时，`planning_clock` 提供当前日期，已有具体时段时再用 `check_plan` 核对容量与冲突。只有时长预算时，先分配这些分钟，日期与时段按实际需要补充。复习能力提供可选估计，普通文档中的路线、证据和后续选择本身即可接续持续学习。
