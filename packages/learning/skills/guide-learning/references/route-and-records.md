# 路线、材料与实际记录

## 从目标形成够用的路线

先读当前语境及它指向的路线和材料，找出用户希望做到什么、何时需要做到，以及已经尝试过什么。目标要具体到能判断结果的程度，例如“能解释并求解一阶线性微分方程”，而不是仅凭“读完第三章”推断理解。已有目标和目录可以继续使用；只有影响当前选择的缺口才需要补问。

据此形成粗路线，保留主要范围、关键先修关系和材料入口，并说明它们为何服务这个目标。建议顺序与必要前置各有作用：建议顺序帮助组织学习，必要前置则说明当前活动为什么暂时做不下去。先修关系随目标要求和实际表现修正，同一主题在入门了解与独立应用时可能需要不同的准备。

全局展开到足以定位当前活动即可。临近要学的部分再补解释、练习或真实任务；远处保留主题和入口。多个目标共享材料或先修时，引用同一份有效内容，并分别保留各自的要求、期限和进展。这样调整一个目标的近期活动时，另一个目标仍有清楚的接续位置。

## 让活动有材料，也有可检查的结果

进入具体活动后，按需读来源的相关部分，再用 `learn-with-feedback` 开展教学。教材、讲义和既有产物优先引用，保留能够再读的定位。新生成的解释、图示、可运行实验和练习则按后续用途保存；图或实验能够解释当前机制时，它们可以成为主要学习活动，而不只是正文的装饰。

活动材料说明当前要解决什么、需要哪些输入，以及怎样检查结果。练习保留可靠的参考答案、推导或验算入口，代码与实验保留运行条件和预期现象；有工具可用时核验关键计算和行为。将学习者可先独立尝试的题目与参考解答分开读取，就能在需要反馈时使用题解，而不把 Agent 给出的答案当作学习者表现。

值得再用的产物保留来源、必要输入和打开或运行入口。内容工具取得的稳定引用用于连接路线、活动和记录；已有材料保持原格式，同一份长期正文在原处维护。可重建的提取结果只帮助阅读，新的路线无需复制整套材料库。

## 用实际记录改变后续帮助

记录围绕已经发生的尝试展开：学习者提交了什么、在哪一步遇到困难、当时用了哪些提示或共同完成的帮助，以及这些事实支持什么判断。原始作答与 Agent 的参考解答分别保存或明确标注，判断关联到具体依据。独立完成、提示后完成和看解后复述提供不同证据；阅读过材料或完成活动本身说明活动发生过，判断独立应用能力还需要相应尝试。

记录中的判断可以暂定，例如“在提示下能选出积分因子，独立选择还需观察”。接着说明下一次用什么活动区分仍然不清楚的情况，并链接到相关材料。新的作答改变了判断时，把当前判断替换成现在成立的说法，再局部调整后续活动；原尝试保留在活动记录或会话历史中。实际用时也保留下来，供下次估计相近活动的工作量。

## 把下一次的入口放进语境

用当前语境工具核对现有绑定；已有正文合适时，通过 `read`、`edit` 或 `apply_patch` 修改相关部分。确需改变绑定或组成时，按工具定义保存，已启用的 `organize-learning` 可以提供格式与操作指导。每次编辑以当前内容为依据，保留人工校订和仍有效的安排。

语境是一份当前入口，而不是按时间追加的记录。它展开近期目标、现在成立的判断、待续活动及下一次观察的简短说明，较长的路线、作答、题解、图和实验保留引用。旧判断被修正后，更新对应的当前段落；判断变化的过程由所链接的记录保留。

例如，学习者已经通过代码对照解释了借用与复制的区别，当前入口可以写成：

> Rust：能解释两个已尝试例子中的借用和最后使用位置。下一步在文本统计函数中独立应用。依据见借用活动记录。

实际维护时把依据写成可读取的引用即可；过去的错误、后来的纠正和每次用时留在活动记录，不在当前入口重复铺开。新会话先据此决定从哪里继续，需要重新判断时再读原文。这样既能取得现在有效的认识，也能回看它是怎样形成的。

## 方法依据

[LearnLM 2024 报告](https://arxiv.org/html/2412.16429v1)将教学指令与具体学习材料分别提供；这里借用这种分离来支持按需读取。[Kestin 等的物理教学研究（2025）](https://pmc.ncbi.nlm.nih.gov/articles/PMC12179260/)为具体活动提供题目部分与教师题解，支持保留局部活动结构和参考依据。[Bastani 等的研究（2025）](https://doi.org/10.1073/pnas.2422633122)区分有辅助练习与无辅助测验，支持记录所用帮助并通过独立尝试修正判断。这些来源提供方法参考，持续跨会话的组织方式仍需在实际学习中检验。
