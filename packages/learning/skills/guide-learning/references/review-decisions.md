# 新学习与复习选择

## 先确定这次选择受什么约束

先读近期目标、期限、待续活动和相关实际记录。涉及相对日期时，使用当前可用的时间能力或用户已明确给出的日期与时区。需要跨目标分配时间时，保留每个目标的要求；共同的先修或活动可以一起推进，但不能用其中一个目标的进展替代另一个目标所需的证据。

候选活动来自当前路线中的下一部分，以及过去尝试暴露的困难或需要再次独立应用的内容。先判断活动是否准备就绪：关键先修不足时，选择能补上卡点的小活动；材料或条件不齐时，先选择可以实际开始的部分。随后结合期限与目标要求，比较哪项活动现在做最能解除阻碍、减少近期风险或推进目标。

## 用证据作近似选择

下面的判断次序用于形成可解释的选择，具体顺序随目标和新反馈调整：

1. 临近期限时，先看目标要求的关键活动还有哪些缺口。优先推进能影响目标结果的部分，必要时缩小范围，并把取舍告诉用户。
2. 当前活动被先修困难卡住时，先补能解除阻碍的部分；如果困难只是局部操作失误，可以在当前任务中修正，不必退回整章重学。
3. 上次依靠提示或参考解答完成的关键步骤，选择一项不同表面情境的独立尝试来检查。已经有可靠独立表现的部分可以继续新学，之后再在更合适的窗口观察保持与迁移。
4. 在可用时间内同时考虑新学习与巩固。巩固活动可以短小穿插，也可以结合新任务检验旧知识；比例按近期困难、目标紧迫性和活动成本判断，不预设每天相同。

掌握判断用实际证据及其范围表达。比如“这次能独立解释变量分离，但处理初始条件仍需提示”足以支持下一步选择；没有相应数据时，不把它换算成掌握概率或固定分数。任务涉及多个知识点时，只更新实际得到证据的部分，成功做完一道题也可能只说明其中某个步骤已能独立完成。

估计工作量时，先沿用相近活动的实际用时，再根据本次材料长度、难度和所需帮助作调整。缺少记录时给出粗估计和关键假设，完成后用实际情况修正。已有具体时段且规划能力可用时，用 `plan-learning` 与 `check_plan` 检查容量；仅有每日分钟数时，直接核对工作量与预算。容量不足时在范围、期限或时间之间作明确取舍，而不是仅提高任务优先级。

## 保存下一次要观察什么

选择之后，在既有安排中保存活动、它服务的目标、选择理由，以及下一次希望看到的表现。例如，“在不看推导的情况下解释积分因子的作用，并独立解一题变式；上次选择因子时用了提示，因此先观察这个步骤”。把这个观察连接到材料和实际记录，下一次就能直接开始，而不必重新推测当时为什么这样安排。

给下一次观察一个大致日期或窗口，并说明理由。需要尽快解除当前阻碍时，可以在近期学习中再试；需要看保持情况时，则留出与目标期限、现有独立表现和可用时间相称的间隔。证据不足时用暂定窗口，下一次依据表现修正，因此“隔日复习”不是所有活动的默认安排。未发生的活动保留为未来安排，过去窗口已错过时按当前事实重新选择。

## 何时使用 FSRS

如果同一学习项可以反复观察，而且每次反馈具有一致含义，可以用已启用的 FSRS 复习能力估计下次时间。这样的学习项可以是概念解释、公式推导、辨析或操作步骤，范围不局限于单词；关键是观察的对象、独立完成的条件与反馈标准足够一致。

已有复习项通过 `review_get` 或 `review_list` 读取，内容与实际反馈继续由复习能力保存。到期列表提供候选，具体活动仍与当前目标和其他工作一起选择。需要核对某次尝试是否已登记或怎样被更正时，再读取相应 `review_history`；普通活动记录可以保留返回的项目和反馈标识，作为后续入口。

先明确这项观察检验什么，再按实际表现保存反馈。提示程度或任务形式显著改变时，先说明可比性并重新判断适用范围；一道综合题的结果不自动给所有涉及知识点增加正向反馈。FSRS 的时间估计与目标期限、先修阻碍和近期安排一起用于选择，它不是跨目标路线的替代物。

评分中的“困难”仍表示已经正确回忆，只是费力；未能回忆或答错使用“再来”。讲解之后的理解与当时是否想起来分别记录，保留学习者明确给出的自评及帮助条件。这一评分含义来自 [Anki 官方说明](https://docs.ankiweb.net/studying.html#answer-buttons)（2026-10-05 核对，本文为摘要）。

维护同一学习项的题面、答案或来源时使用 `review_update`，已有表现继续保留。发现旧反馈录错时使用 `review_correct`；新增实际尝试才使用 `review_feedback`，回填旧事实时带上实际发生时间。它们分别维护学习材料与已经发生的学习，修改答案本身不增加复习次数。

尚未形成可比反馈的活动，以及关闭或未启用 FSRS 的空间，继续在普通文档中保留尝试、理由和下次窗口即可。重新启用算法时按已有能力读取真实记录与估计，不从助手总结伪造反馈序列。
