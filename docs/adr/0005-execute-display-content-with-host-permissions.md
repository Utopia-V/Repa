# 按应用授权运行命令与展示内容

本记录约定目标设计；当前实现范围与运行方式见 [README](../../README.md#运行现有-tui)。

## 授权与调用范围

应用持有授权，能力入口根据实际调用上下文检查操作与目标范围，相应执行环境落实限制。完整前端通过认证连接承担用户的操作界面，包括设置与授权答复；Agent 工具和展示实例通过各自入口使用已授予的能力。后端根据实际连接、运行或展示实例建立调用上下文，工具参数中的批准标记、页面声明和组件角色名称不自行改变授权。读取、订阅、资源访问和修改均遵循相应范围，资源地址与标识本身不构成授权。

默认允许在当前学习空间的授权内阅读与编辑学习内容，明确加入的外部材料允许读取所引用原件，修改原件需要另有写入授权。运行账本、权限配置和连接凭据等应用管理状态由所属模块维护，普通内容写入权限不包含这些状态。使用已配置的模型连接和已启用的搜索等网络能力时沿用其已有授权；练习代码与本地命令使用当前空间的执行策略，新增空间外写入或扩大网络访问范围时请求所需授权。

权限请求复用应用协调层的待回答交互，绑定实际操作、目标、所缺访问范围及授权有效范围。后端持有这些事实，前端展示并提交答复；多个前端观察同一待回答项，共用其最终答复。普通插件确认框不自动修改授权，已经取消的操作不因迟到答复重新启动。已有授权覆盖的后续调用直接执行，关联与去重由适配层、客户端及后端处理。

## 命令执行

模型侧命令工具优先复用 Pi 的 `createBashToolDefinition()` 等工具工厂，通过 `BashOperations.exec` 把实际进程执行接到 Repa 的授权与执行环境。参数、输出处理及工具结果继续使用适用的现成实现；执行适配器核对取消、超时、进程收尾及输出资源的可访问范围。当前 SDK 接口依据见[通用原语核验](../research/pi-ecosystem-compatibility.md#通用-agent-原语与应用边界)。

命令执行层优先复用 [Codex 的开源沙箱模块](https://github.com/openai/codex/tree/3d2ee51ca2d5db578f328aa75e20aa22c0197c9a/codex-rs/sandboxing)，由 Repa 自行集成、配置和交付，正常使用不要求安装、登录或配置其他 Agent 应用。执行适配器报告实际支持的文件、网络和进程限制，按选定策略执行；不能满足条件时明确返回不可执行原因，不自动放宽权限。同宿主加载的插件代码仍属于其运行环境的信任边界，命令沙箱不自动隔离全部插件代码。

命令可能在部分操作完成后才遇到权限拒绝。执行器返回真实输出、退出情况和已知拒绝原因，获得额外授权不自动使整条命令成为可以安全重跑的请求。尚未执行的请求可以继续，已执行或结果不明的请求沿用结果查询与恢复语义，Agent 根据实际结果决定后续操作。

## 展示内容与交互

插件提供展示能力，Agent 或工具生成的各类产物作为内容交给相应渲染器。Markdown、公式、图片与结构化图表等由可信组件显示；需要脚本的交互内容默认在独立展示环境中执行。安装启用的插件代码属于应用的运行组成，生成文件本身不自动取得插件身份与权限。保持这个边界，使交互内容可以持续产生，而应用能力的启用仍由宿主拥有。

内容、数据、资源与动作通过公开契约组合，同一份内容可以具有多种展示与交互方式。能力说明其输入、输出和操作，Agent 可利用已启用能力生成不同产物并继续重组；具体格式、渲染和计算方式由相应能力提供。产物需要保留的组成与资源通过[共同内容操作](0003-share-file-based-content-operations.md)保存和维护。

每个展示实例取得明确提供的数据、资源和动作，例如本次实验数据、打开来源、提交结果或请求解释。普通实例不取得完整 Repa 客户端或后端主连接令牌；读取额外材料或执行其他操作时，通过宿主按当前授权处理。宿主检查消息来源、参数和目标范围，页面提供的文字、数值及权限声明保留为该页面的内容或输出，不自行升级为用户指令与授权。

同一内容可以打开为多个独立展示实例，各自保留所用内容的引用、修订与交互状态。源内容更新后，实例可以继续使用原输入，或按相应能力的更新方式刷新。保存结果时保留实例实际使用的来源；动作需要修改源内容时，使用相应修改基准处理期间的变化。关闭实例后，已提交的后端操作继续按自身生命周期处理，结果仍可查询。

展示宿主在打开实例和取得额外资源时，统一建立对实际使用的受管理版本与资源的临时持有。清理历史不打断仍有效的旧实例；新打开的实例按所选版本建立，普通打开使用当前内容。实例关闭或宿主被确认失效后释放持有，短暂断线沿用重连机制。异常结束后若旧输入已不可恢复，明确说明，不以新版本替代并冒充原输入。

保存结果或提交后台处理时，相应文档或请求建立自己的必要资源保留关系；仍有效的展示实例继续持有所用资源，保存或提交本身不结束这份持有。实例之后释放资源时，已提交请求或文档的独立保留关系继续成立。相同资源可以共用存储，临时持有不另建持久业务对象或历史记录；范围限于 Repa 管理并提供给实例的版本与资源，外部原件继续遵循材料引用语义。具体保留与回收由[共同内容操作](0003-share-file-based-content-operations.md#材料与资源生命周期)承担。

缩放、拖动、调参和动画在展示内部完成。保存结果和提交练习通过宿主动作写入已授权目标，向 Agent 提问时把当前状态组成可见请求，已有授权覆盖的动作直接执行。页面计算结果与学习判断保留各自含义，普通交互不持续触发模型请求。

## 授权变更与历史产物

用户可以显式选择 Full Access，放宽相应范围的数据、工具、网络或其他执行权限。宿主明确显示作用范围，按当前授权决定实际可用能力；权限放宽不改变内容来源、操作记录和生命周期的含义，也不把页面自身的权限声明视为授权。

运行保留实际使用的配置和代码版本，后续受保护操作仍检查当前授权。收紧权限时，尚未开始的操作按新范围检查；已运行命令持有被收回的权限时停止受影响的执行并确认实际结束；展示实例关闭受影响的通道，必要时重新建立；已加载可信插件的执行能力通过停止或重启相关宿主解除。界面区分已要求停止和实际停止，已完成的修改与已发出的请求保留为发生过的事实，收回授权不撤销这些结果。

会话中的展示产物保留重新打开所需的内容和输入数据，这些数据随会话持久保存，可重建的部分才作为缓存管理。持续维护的结果保存为文档并进入内容引用、修订与编辑体系，同时保留文档必需的资源，其生命周期独立于原会话的清理；缩放位置、动画进度等交互状态由前端按需保存。需要保留的运行和交互结果关联实际使用的内容修订与输入，后续编辑源内容不改写已有结果。重新打开历史产物时按当前授权建立实例，旧声明不恢复已失效的权限，重新运行计算或 Agent 调用形成可识别的新操作。

渲染器须声明并实际满足所需的执行条件，分别处理宿主访问隔离、资源加载、对外连接、导航与消息桥接。无法满足条件的前端提供静态结果或源码视图，并说明相应交互能力不可用；不通过自动放宽权限继续执行。具体接入由真实运行环境验证。可优先评估复用 [MCP Apps 的 AppBridge 等 SDK 模块](https://github.com/modelcontextprotocol/ext-apps#using-the-sdk)，其[隔离与通信规范](https://github.com/modelcontextprotocol/ext-apps/blob/main/specification/2026-01-26/apps.mdx#sandbox-proxy)作为接入依据；具体渲染宿主仍需集成与验证。
