# Repa 学习功能：全局粗览与局部细化

2026-10-05 设计与研究记录。这里的全局与局部，指 Repa 学习 Agent 对学习目标、学习者现状、知识范围与学习路线的整体认识，以及对具体内容的按需展开。已接受的产品语义由 [CONTEXT.md](../../CONTEXT.md) 持有，本文展开其设计问题，具体算法与实现由 [#38](https://github.com/Utopia-V/repa/issues/38) 接续。MA 的公开组织方式见[参考摘要](math-academy.md)。

## 全局粗览与局部细化

学习组织首先需要足以判断方向的整体认识。模型可以结合自身知识、课程大纲、教材目录和其他相关资料，形成主要范围、关键联系、可能路线及其与当前目标的关系。远处内容先保留粗略位置和用途，当前决策相关的部分再展开到可操作的程度。

这里的懒加载同时涉及读取和细化：已有详细资料可以按需读取，尚未形成的局部结构也可以在需要时再建立。它控制展开成本，全局认识则提供方向和优先级。两者配合，才能在保持视野的同时减少无用工作。

整体认识允许有空白和待确认之处。先把依据资料可知的主要范围放在合适位置，再随着实际学习补充，避免用大量临时生成的细节营造完整路线的外观。重要反馈、新资料或目标变化影响原判断时，再修订整体认识及有关局部。

## 局部展开围绕当前决策

某个知识点可能不断引出前置概念和旁支。是否继续展开，应看它对当前目标及下一步判断的作用。足以完成当前工作时，可以保留后续入口并转向其他值得推进的部分；困难确实来自某项基础时，再深入相应范围。这样，内容相关性不会自动变成学习必要性。

需求和当前水平尚不清楚时，先补充会改变路线选择的信息。资料、已有工作和一次有针对性的尝试都可以帮助判断；确实需要本人决定的目标与取舍再询问学习者。澄清应当缩小关键未知，其余已有依据的工作可以继续。

全局认识也参与局部决策。只在已展开的内容中选择，会偏向当前熟悉或容易描述的分支；保留其他目标、主要空白和大致依赖，才能判断当前深入是否仍值得。具体展开范围随目标、熟练程度和投入变化，不采用适用于所有人的固定深度或题量。

## 目标要求与当前表现分别考虑

应试、长期理解和实际应用可能涉及相同内容，却要求不同的深度、速度和保持时间。当前表现属于已有认识；是否足以满足某个目标，需要结合该目标判断。同一份理解可以暂时满足一项要求，同时仍不足以承担另一项任务。

因此，复习也由目标决定。应试安排需要结合考试范围、时间和实际薄弱处；长期学习还要考虑基础积累、迁移和持续保持。方法随这些条件变化，不能仅由一个统一到期列表决定全部学习安排。

## 多个目标共同影响安排

多个考试目标可能时间不同、熟练程度不同，又与长期学习目标重叠。选择下一项活动时，需要综合剩余时间、目标要求与现状的差距、重要依赖和预期投入。最近的期限有实际影响，其他目标的准备成本和后续需要也应保留在整体判断中。

相同知识的一次有效练习可以服务多个目标，实际表现也可被共同使用；各目标对这份表现的要求仍然不同。具体任务可以合并或调整，避免为每个目标重复安排同一工作。某项目标完成后，其留下的内容与认识仍可以服务后续目标。

这些因素用于推导安排，当前没有必要先规定统一的权重公式、总分或调度流水线。算法研究应逐步明确哪些判断适合程序计算，哪些依赖模型对材料、活动和反馈的理解。

## 与当前 Repa 机制的关系

现有内容操作、学习语境和工具可以保存并按需读取整体认识、材料和局部成果。先用这些能力支持实际判断，再根据具体缺口改进表示或接口。

[ADR 0002](../adr/0002-progressively-load-learning-context.md)约定的是模型输入中哪些内容展开、哪些保留引用，以及运行快照和压缩接续。本稿讨论学习范围与路线怎样逐步形成，两者处于不同层次；输入机制可以承载相应内容，学习判断仍由使用它的方法和能力承担。

现有 [FSRS 复习插件](../development/review.md)提供记录与调度服务，学习任务选择和算法适用性由 [#38](https://github.com/Utopia-V/repa/issues/38) 继续研究。工作表示、元操作和方法改造归 [#30](https://github.com/Utopia-V/repa/issues/30)。后续从具体问题形成可工作的做法，再按实际缺口调整表示与接口。
