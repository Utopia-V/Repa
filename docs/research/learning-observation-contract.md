# 函数作答的观测目标与帮助条件

2026-10-10。学生状态需要消费实际作答，但在使用一个“正确”结果之前，还要知道它判定了什么。[已有内容核对](learning-evidence.md)发现，同一表达式等价比较会接受代入式和最终化简式，因而不能从步骤标题还原学习者完成的操作。本轮继续使用固定函数材料，改为明确回答对象，并分别保留题面、帮助条件、程序输出与独立数学判断。28 项合成响应及完整核对结果见[公开记录](results/learning-observation-contract-20261010.json)。

本次形成了可检查的局部观测条件，而不是两个已经识别的隐藏技能。字段检查能够区分所要求的系数是否相符；抽象表达式比较则暴露了更强题面要求与现成比较器语义的差别。两者都还需要结合实际作答条件解释。

## 先说明要求回答什么

材料来自 [OATutor-Content `1925decc`](https://github.com/CAHLR/OATutor-Content/tree/1925decc91567faf6203bdb41b9d52b14891426f) 的 `a005bd5real2` 题族，给定：

$$
f(x)=x^2+2x,\qquad g(x)=6-x^2.
$$

正确的差式为 $x^2+2x-(6-x^2)$，整理后为 $2x^2+2x-6$。本轮沿用这些函数，另写中文题面、回答目标及帮助条件，保留原题库和原错误参考不变。内容来源为 OATutor 团队，按原 CC BY 4.0 许可注明来源与改动；这些新条件不是上游历史学生记录。

| 条件 | 已经给出的信息 | 需要提交的回答 |
| --- | --- | --- |
| 抽象差含义 | 在任意固定 $x$ 处，令 $u=f(x)$、$v=g(x)$ | 用 $u,v$ 表示 $(f-g)(x)$，要求对任意实数 $u,v$ 有定义并相等 |
| 给定表达式 | $x^2+2x-(6-x^2)$ | $x^2$、$x$、常数项的三个系数 |
| 函数差问题 | 上述 $f,g$ 及 $(f-g)(x)$ 的要求 | 同一组系数 |
| 已提供正确差表达式 | 保留函数差背景，并直接给出正确代入式 | 同一组系数 |
| 完整答案已曝光 | 直接给出三个系数 $2,2,-6$ | 同一组系数，作为条件解释的负对照 |

系数输入的设计意图是三个带位置标签的填写处，而不是要求学习者手写数组或 JSON。当前矩阵用键值对象调用纯函数，尚未实现或验收这份界面。

改变回答对象是实质性的任务修改。现在可以检查学习者是否给出了三个所需系数，却仍不能断言其在心中执行了某一条化简路径。直接相减系数、先展开括号或按项处理，都是可以完成目标的解法。

## 上游返回相等，支持哪一种判断

表达式部分直接调用固定 [OATutor `939eb0e3` 中的 KAS](https://github.com/CAHLR/OATutor/blob/939eb0e30d8ae2389c8b096c8cd522713a79090e/src/kas.js)。普通变量表达式的比较使用有限数值抽样和 `1e-9` 容差，抽样前还会整理表达式；它不是对任意实数及原式定义域的精确证明。变量检查也只要求输入变量属于参考变量集合，而不要求两边的变量集合完全相同。[实际比较路径](https://github.com/CAHLR/OATutor/blob/939eb0e30d8ae2389c8b096c8cd522713a79090e/src/kas.js#L1793-L1922)。

本轮保持原库字节不变，在隔离 VM 内加载现有 KAS 和 underscore，为两者提供同一个预定随机流。每项输入重置到 seed `20261010`，保存解析、变量检查、完整比较返回以及实际消费的随机值，并将比较与辅助表示的消费位置分开。固定随机流用于复核本次路径，不用来估计比较器的误判率。

| 输入组 | 本次数值比较 | 独立数学判断 |
| --- | --- | --- |
| `u-v`、`-v+u`、`u+(-v)`、`2u-u-v` | 四项均返回相等 | 都在完整要求的定义域上恒等 |
| `v-u`、`u+v`、`0` | 三项均返回不等 | 都存在简单反例，例如选择 $u=1,v=0$ 或 $u=0,v=1$ |
| `(u^2-v^2)/(u+v)` | 返回相等 | $u+v=0$ 时原式未定义，不满足题面要求 |
| `(u-v)*u/u` | 返回相等，整理后成为 `u-v` | 原式在 $u=0$ 时未定义，整理丢掉了这个条件 |
| `u-v+1/1000000000000` | 返回相等 | 比目标精确多出 $1/10^{12}$，不是恒等式 |
| `u-w` | 变量检查后返回不等 | 使用了题面没有给出的变量 |
| `u-` | 解析失败，未进行比较 | 表达式缺少右项 |

十二项中，七项返回相等、四项返回不等、一项解析失败。两个定义域反例和微小非零差说明，本题较强的“任意实数上精确相等”要求不能由 `equal=true` 单独支持。这是题面命题与比较机制的适配问题，不把本组特意选取的反例比例当作上游实际教学中的错误率。

因此，当前保留上游实际结果与独立数学判断两份证据，不为这个小范围核对另造通用代数系统。自动判断不能确认的域与表达式范围应当显露出来，后续可以使用合适的证明机制或人工核验；也不能因为形式超出支持范围，就直接解释成学习者不懂相应知识。

## 系数检查怎样区分错误与未判定

系数部分只检查三个明确的位置。局部原型要求每项为不超过 30 个原始字符的字符串，允许首尾空白、普通正负号、Unicode 负号和常见十进制写法。处理后的十进制文本转换为整数比例，再精确比较目标 $2,2,-6$，没有使用浮点容差。

这份小范围规则将结果分为三类：三个有效常数都相符时为 `matches`；常数可评估但有差异时为 `does_not_match`；缺项、多项、类型不符或超出本次写法范围时为 `unassessed`。最后一类说明本检查器没有完成判断，不是数学错误。

16 项系数响应实际得到五项相符、三项不符、八项未判定：

- `2`、`+2.0`、带空白的小数及 Unicode 负号等预定变体得到相同判断。
- 原错误参考对应的 $(0,2,-6)$、函数和对应的 $(0,2,6)$、反向差对应的 $(-2,-2,6)$ 都与当前差式目标不符。
- 把未化简整式塞进一个位置，不再被当作已提交三个正确系数；缺字段、额外字段、非字符串、非有限数值写法和超长输入也分别保留原因。
- `4/2` 在数学上可以表达正确常数，但超出本次十进制字段检查的范围，因此保留为未判定，而不是错误。这项限制属于研究原型，不是已经采用的产品输入规则。

相同的正确系数在给定表达式、函数差、已给中间式和完整答案曝光条件下都判为相符。检查器没有为了表达诊断价值不同而篡改回答对错；这些区别由各自的题面与帮助条件继续承载。

## 这些条件还没有识别两项隐藏能力

抽象的 $u-v$ 问题只问逐点差的含义，而具体函数差还需要把函数定义绑定到式中，并保留整个被减多项式的范围。因此，即使抽象题答对、综合题答错，也不能仅由逻辑排除其他解释，把错误全部归给代数化简。

同样，提供正确差表达式不只是去掉一个抽象符号步骤。它同时给出了正确实例化和分组，也可能帮助学习者注意负号。当前可以确定删去了哪些题面要求，却没有证明这个帮助只影响一项潜在能力。给定表达式与受助函数差虽然有相同的数学输入，实际语境仍可能改变表现；先前合成模型的相同猜测、失误或教学参数不能直接沿用。

本轮九项实现单元检查通过。正式 28 项矩阵只运行一次，独立核对保留了所有原响应与条件，重新验证了 16 项系数分类、24 个整数比例以及全部 174 个随机值；来源和实现摘要在执行与审计前后相同。这里完成的是内容与判断谓词的核对，尚无本题的真人逐动作或后续不受助表现。

## 对接入与后续研究的含义

现有[学习判断接口](../development/learning-attempts.md#候选判断与采用)已经区分固定事实、方法、依据及逐项 `criterion`，并允许 `met`、`not-met`、`undetermined`。这份研究与其责任相符：程序返回的某项比较相等、回答满足当前要求，以及某项能力如何变化，是不同命题。判断方法和范围应保存在相应依据中，而不是把它们一起压成不带条件的正确标记。

下一步需要能够关联具体题面、帮助与后续不受助回答的实际证据。真实学习者也不应为了模型辨识而在每道题上重复完成整组探针；短诊断应服务当前的不确定性，后续题需要避免只是记住同一答案。当前内容核对提供了这类取证的可检查起点，跨题稳定性、求助选择及实际学习改变仍需分别检验。
