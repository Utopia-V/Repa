# 局部状态表示能保留哪些后续推断

2026-10-10。本文接续[学习期间的状态更新](learning-state-update.md)，固定相同的观测与教学转移，只比较状态压缩造成的差异。全部分支和预测结果见[聚合数值](results/learning-local-state-20261010.json)。这项核对用于选择候选表示，不评价真实教学效果，也不为产品指定未经校准的学生模型。

## 从两个共享技能的任务开始

设三项二值技能 A、B、C，初始独立具备概率分别为 $4/5$、$2/5$、$3/5$。一道题所需技能都具备时，答对概率为 $19/20$，否则为 $1/10$。先观察 AB 题失败，再观察 BC 题失败，期间不发生学习。之后只教 B：原来不会 B 的状态以概率 $r$ 转为会 B，原来会的保持，A、C 不变，也不考虑遗忘。

静态阶段只用了 AB 和 BC 两个观测因子，因此完整后验可以准确写成一棵以 B 为中间节点的树。问题在于，教学之后的 B 已经不一定等于两次失败时的 B。如果只保存当前 A、B、C 的关系，原来的树还够不够？如果把三个两两边缘都保存下来，又能否完全解决这个问题？

核对使用 $r=0,1/4,1/2,3/4,1$ 的全部分支。另把同样的教学放在叶子 A 上作为对照，不按结果调整参数。每个分支先算出精确当前分布，再只压缩一次；后续观察沿压缩后的分布计算，因此这里隔离的是这一处信息损失，不是多轮在线近似的总体误差。

## 比较的是哪几种表示

| 表示 | 保留的信息 | 本次解释范围 |
| --- | --- | --- |
| 完整当前联合分布 | A、B、C 的八种状态 | 小规模精确参照 |
| 独立边缘 | 三个单项概率 | 丢弃全部关联的对照 |
| 固定树 | AB、BC 两对关系及一致的单项边缘 | 沿用原静态树 |
| 最佳当前树 | 枚举三棵树，用精确边缘重建，并选择当前 $D_{KL}(P\|Q)$ 最小者 | 使用精确参照选树的理想对照，不是已实现的在线策略 |
| 全部两两边缘的最大熵分布 | 三个单项、三个两项矩完全相同，再以最大熵选择剩余自由度 | 保留全部一、二阶矩；正支持时三阶对数项为零 |
| 保留旧 B 的局部结构 | 旧 B 的权重，以及给定旧 B 时各当前技能的条件概率 | 本例中的精确正对照，适用操作范围另行核对 |

树重建采用一致的边缘。例如固定树使用 $Q(A,B,C)=P(A,B)P(B,C)/P(B)$；零质量切片保持为零。三棵树全部报告，不把固定树的失配概括成所有树都不合适。按 KL 选择树的准则也有现成依据，但该准则不承诺任意后续预测或行动损失都最小。[Chow–Liu 原论文，第462—464页](https://cs.nyu.edu/~roweis/csc2515-2006/readings/chowliu.pdf)。

三个二值变量的一、二阶矩和归一化共提供七个独立约束，因此八格分布还剩一个自由度，可以取 $z=P(111)$。最大熵投影在非负性给出的合法区间内求解；本次使用有理数二分，保留根区间，没有为零概率加平滑。非退化分支的区间宽度小于 $7\times10^{-50}$；约束和边缘保持精确，根值的数值近似范围单独记录。公开聚合值舍入为最多 18 位有效数字，根区间则保留原分数。

## 为什么两两信息仍然不够

按 `000,001,010,011,100,101,110,111` 排列，两次失败后的静态后验是：

$$
(162,243,108,9,648,972,24,2)/2168.
$$

给定旧 B 后，A 和 C 仍然条件独立。但教过 B 以后，当前 B 为 1 的状态混合了两种来源：原来已经会 B，以及原来不会、现在学会。两种来源对之前失败的解释不同，也对应不同的 A、C 条件分布。消去旧 B 后，这个混合会在当前状态中形成原树没有表达的关系。

对于正概率的八格，可以用三阶对数交互核对：

$$
\tau=\log\frac{p_{111}p_{100}p_{010}p_{001}}
{p_{110}p_{101}p_{011}p_{000}}.
$$

如果分布的对数只由当前单点和两点项相加构成，这些项在上述比值中会相消，因而 $\tau=0$。这里说的是对数交互为零，不是 $P(111)$ 为零。本例中，$0<r<1$ 时精确分布的 $\tau$ 非零，因此既不能由任何一棵当前三节点树精确表达，也不等于保留全对矩后的最大熵分布。

端点则不同：$r=0$ 时原树精确；$r=1$ 时当前 B 确定为 1，只需保留 A、C 的联合关系，含 AC 边的树和全对矩表示重新精确。此时三阶公式含零格，不定义其有限值，也不靠加 epsilon 把它伪装成普通点。叶子 A 的教学对照在全部五个 $r$ 下都保留原树结构，说明不是每次学习都要求扩大表示。

## 差异在什么查询中出现

全对矩表示在压缩时保留了所有单项和两项题的预测。观察一次 A 后，单项 C 的预测也仍然准确；但此时 BC 的预测可能已经不同，因为它用到了三个变量共同出现的概率。继续观察 B 后，差异就会进入单项 C 的预测。

## 保留一项旧状态，可以精确到哪里

这段有限序列有一种不展开全课程联合状态的精确保留方式。暂时保留旧 B，用以下局部形式表达当前分布：

$$
P(A,B',C)=\sum_{b_0}P(b_0)P(A\mid b_0)P(C\mid b_0)T(B'\mid b_0).
$$

这里的条件概率来自两次已有作答后的判断，不把这幅推断结构解释为课程的先修图或技能之间的物理因果图。实现只保存旧 B 的两个权重及各分量的当前单项概率。收到一个单项观察时，更新相应条件概率和旧 B 的权重；预测 BC 时则计算两分量内 B、C 同时具备的概率后求和。

这一实现没有把当前八格作为自己的状态；在十个情境（共享 B 与叶子 A 的教学各五档）中，它与精确枚举的当前分布及所有单项观察路径完全相符。因此，本例并不要求立即改成全局完整联合分布，也不要求永久保存每个旧时点。

不过，能预测下一道 BC 的结果，不等于收到这个结果后还能沿用同一结构。在 $r=1/2$ 的旧 B 为 0 分量内，消费 BC 失败后，当前 B 与 C 的条件协方差变成 $-204/1849$，不再独立。此时要保留这个新关系、扩大局部因子，或明确进行近似；继续直接相乘就会再次丢掉信息。表示的适用范围因此要同时说明可回答的查询，以及哪些新证据能在该表示内正确接续。

## 对候选实现的判断

当前结果不支持把一份固定树或全对矩快照当作所有后续推断的充分状态。接下来优先试作能够保留局部必要关系、并在复合证据到达时显式调整作用范围的表示；独立边缘、树和其他压缩仍可用于允许近似的位置，但要检查它们影响的是哪些查询，而不是只核对当前几项边缘概率。

紧凑的动态过程也不保证每个时点的后验都同样紧凑，这是近似动态推断已有的核心问题。现有误差界有自己的混合和期望条件；本例只改变一个技能，其他技能保持不变，不能直接援引它来保证任意观察路径的误差都会收缩。[Boyen–Koller 1998，第1节、第3节及第5.1节](https://ai.stanford.edu/~koller/Papers/Boyen%2BKoller%3AUAI98.pdf)。

本次没有测量全课程运行成本，也没有把精确参照用于在线选树的代价算成免费。下一步需要在继续到达的综合证据中核对局部表示的增长和查询代价，再与明确允许的近似比较。真实学生模型的观测函数、学习转移与帮助条件仍需按[既有研究问题](learning-loop.md)取证；这里的表示核对不替它们提供有效性结论。
